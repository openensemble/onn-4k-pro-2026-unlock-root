Full README ↗
!

Read this before unlocking.

Unlocking requires a factory reset in Android Recovery on the TV. It erases all user apps, accounts, settings and other local data. Unlocking or rooting could permanently brick it. Back up anything you want to keep. After the unlock reboot, follow recovery's on-screen controls to complete the reset. A proven way to restore a bad root installation is not available for this workflow.

The script asks you to choose Accept or Decline. Read the recovery limitations ↗

What you need

  • An x86-64 Linux computer, Python 3.10+ and at least 12 GiB free.
  • The supported onn firmware, at least 8 GiB free, a TV, its remote and steady power.
  • Your computer and onn on the same network.
  • Android NDK 28.2.13676358, installed through Android SDK Manager.

The guide finds the NDK or asks for its folder. It explains how to enable Developer mode, USB debugging and Wi-Fi debugging, including after the unlock reset.

Enter the onn’s IP address the first time. Give it any name you like; its hardware serial keeps the correct unit selected.

04 / GOOD TO KNOW

A few practical
details.

Can this handle multiple onns or a changed IP?

Yes. Add each supported 2026 unit once using its IP address, then choose it from the saved-device list. Each keeps its own progress and backups. After an address change, the guide looks for the same hardware serial. If it cannot verify the unit, it asks for help rather than selecting a different onn.

Does the script handle the restarts?

It requests the unlock, verified root-install and temporary-system restarts automatically. After the unlock reboot, you must complete the factory reset in Android Recovery on the TV; this erases all user apps, accounts, settings and other local data. The temporary-system return test still needs one physical power cycle. Magisk handles its own setup restart after you accept its message on the TV. An uncertain reboot request is never automatically repeated.

Can I stop and continue later?

Type q at a prompt, then run python3 onn2026.py again to continue. Keep the computer’s work/ folder with its progress, backups and attempt records. An uncertain write or reboot stops for inspection instead of being replayed.

What happens to automatic updates?

The guide disables automatic Android system-update scheduling and checks the setting before reporting completion. App updates are separate, and manual system updates remain available.

Is this the installer for the 2024 onn?

No. The earlier jarvis / SNA hardware has a separate 2024 unlock and root guide. Use the installer for your exact model and firmware.
